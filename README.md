# Power BI Training Program

A 10-day practical Power BI training program designed and delivered during my cooperative training at the Data and Statistics Center of Qatif Municipality.

## Overview

The program was designed to help beginners develop practical skills in data preparation, cleaning, analysis, visualization, and dashboard development using Microsoft Power BI.

## Training Topics

- Introduction to Power BI and its main components
- Importing and cleaning Excel datasets
- Creating charts and interactive dashboards
- Using filters, slicers, and bookmarks
- Data transformation using Power Query
- Working with KPIs and advanced visualizations
- Using Smart Narrative for analytical insights
- Completing a practical final project

## Final Project

The training concluded with a practical project involving multiple datasets, data cleaning, table relationships, dashboard development, KPIs, and business insights.

## Tools

Microsoft Power BI, Power Query, and Microsoft Excel.

## Purpose

This repository documents the training materials, practical exercises, and projects used during the 10-day program.
